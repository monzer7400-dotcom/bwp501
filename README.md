# دليل فعاليات الجامعة الافتراضية السورية

مشروع مقرر 501BWP باستخدام PHP وMySQL وBootstrap وJavaScript. الواجهة باللغة العربية، واتجاهها RTL، وتعمل صفحات الفعاليات على بيانات قاعدة البيانات بدل كتابتها في HTML.

## التشغيل محليًا عبر XAMPP

1. ثبّت XAMPP مع PHP 8.1 أو أحدث وفعّل خدمتي Apache وMySQL.
2. انسخ مجلد المشروع إلى `C:\xampp\htdocs`.
3. افتح phpMyAdmin على `http://localhost/phpmyadmin`، ثم استورد `database.sql`.
4. إذا كانت بيانات اتصال MySQL مختلفة عن إعداد XAMPP الافتراضي، اضبط متغيرات البيئة `DB_HOST` و`DB_NAME` و`DB_USER` و`DB_PASS`، أو عدّل القيم الافتراضية في `db.php`.
5. افتح `http://localhost/ibrahem_112299-c4-ahmad_229900-c3/` (استخدم اسم المجلد الفعلي إن غيّرته).

يتطلب المشروع إضافتي PHP `pdo_mysql` و`mbstring`. تُنشأ قاعدة `events_city` وجداولها وبيانات الفعاليات النموذجية عند استيراد الملف. ينشئ الموقع حساب الإدارة عند أول اتصال إذا كان جدول `users` فارغًا.

## دخول لوحة الإدارة

افتح `/admin/login.php` وسجّل الدخول باسم المستخدم `admin` وكلمة المرور `admin`. غيّر كلمة المرور الافتراضية قبل رفع الموقع إلى الإنترنت. لإنشاء تجزئة لكلمة مرور جديدة باستخدام PHP:

```sh
php -r "echo password_hash('كلمة-مرور-جديدة', PASSWORD_DEFAULT), PHP_EOL;"
```

ثم حدّث قيمة `users.password` لهذا المستخدم بالتجزئة الناتجة.

## محتوى المشروع

- `index.php`: الصفحة الرئيسية والفعاليات البارزة والتصنيفات وأعضاء المشروع.
- `events.php` و`event.php`: قائمة الفعاليات، البحث والتصفية، التفاصيل، المشاركة والتقويم.
- `about.php` و`contact.php`: تعريف الدليل والفريق والسياسات ونموذج التواصل.
- `admin/`: تسجيل الدخول والخروج ولوحة التحكم وعمليات CRUD.
- `database.sql`: مخطط قاعدة البيانات وفعاليات نموذجية.
- `assets/`: تنسيقات CSS وسلوك JavaScript.

## قبل التسليم والنشر

- راجع أسماء أعضاء الفريق وأرقامهم في `index.php` و`about.php`، وأكمل العضو الثالث على الأقل. الاسمان والرقمان الحاليان مستنتجان من اسم مجلد مساحة العمل وليسا تأكيدًا لهوية الطلاب.
- استبدل البريد العام وروابط التواصل بحسابات الفريق المعتمدة.
- ارفع المشروع وقاعدة البيانات إلى استضافة تدعم PHP وMySQL، ثم اضبط متغيرات اتصال قاعدة البيانات. هذا المستودع لا يتضمن استضافة أو رابطًا عامًا.
- لا تستخدم كلمة المرور الافتراضية `admin` في الاستضافة العامة.
